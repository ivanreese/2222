# 2222 in Nova

Contributed by [June Gardner](https://june.codes)

To play this version:
1. Download `2222.nv` to your computer.
2. Download `wordlist.nv`.
3. Get [Serpens](https://forge.nouveau.community/nouveau/serpens), an implementation of Nova written in Python
4. Put all three files together in a folder.
5. Make sure you have python, then run: `./nova.py 2222.nv wordlist.nv`
